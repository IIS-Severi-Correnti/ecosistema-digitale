# Architecture Decision Records (ADR)

Ogni decisione architetturale importante avrà un documento versionato con:

- **Stato**: proposto, accettato, respinto, superato.
- **Data**, ambito e referenti del confronto.
- **Contesto** e problema.
- **Alternative** realmente considerate (incluso mantenimento/miglioramento dell'AS-IS).
- **Decisione** motivata, eventuali vincoli e impatti.
- **Conseguenze**, rischi e verifiche necessarie.
- **Riferimento all'approvazione istituzionale**, se applicabile.

Un ADR è uno strumento di trasparenza tecnica: lo stato `accettato` documenta una decisione progettuale solo se il soggetto competente l'ha effettivamente approvata.
