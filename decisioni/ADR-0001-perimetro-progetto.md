# ADR-0001 — Perimetro del repository

- **Data:** 2026-10-12
- **Stato:** proposto per formalizzazione istituzionale
- **Ambito:** organizzazione del lavoro tecnico-documentale

## Contesto

Il progetto nasce dall'esigenza di razionalizzare gli account Microsoft, ma riguarda anche posta, sistemi operativi, postazioni, governance e automazioni.

## Alternative

1. Repository limitato alle identità.
2. Repository generale per l'ecosistema digitale.
3. Repository diversi per ogni sottotema.

## Scelta proposta

Utilizzare `ecosistema-digitale` come **punto di riferimento documentale generale**. Mantenere repo autonomi per progetti di laboratorio o software con ciclo di vita indipendente. Pubblicare soltanto documenti non sensibili; collocare le evidenze riservate nei sistemi istituzionali autorizzati.

## Conseguenze

Maggiore continuità, collaborazione aperta e possibilità di riuso; necessità di revisione rigorosa dei contenuti pubblici. La licenza documentale è da decidere dall'istituto.
